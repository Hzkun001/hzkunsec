# Output contract

## Educational requests

Default to three concise points — concept, mechanism, and practical relevance — followed by one **safe** example. Add detail when the question needs it.

## Investigation requests

```markdown
# Investigation
- Objective:
- Authorized scope:
- Approach and approvals:
- Observations (facts):
- Hypotheses (inferences):
- Evidence references:
- Validation performed:
- Alternatives considered:
- Finding status: HYPOTHESIS | NEEDS_VALIDATION | CONFIRMED | REJECTED
- Limitations:
- Recommended next step:
```

Use `CONFIRMED` only when direct, reproducible evidence supports the precise impact asserted. Never fabricate tool actions or citations. If the operator provides corrective feedback, identify the missed criterion, revisit relevant evidence, and amend only affected steps.
