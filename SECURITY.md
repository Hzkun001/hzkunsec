# Security Policy

## Responsible use

hzkunsec contains research workflows for **authorized** systems only. Respect scope, rules of engagement, data minimization, and testing windows. Intrusive or state-changing tests require human approval. Never store real credentials or private customer data in issues or pull requests.

## Report a vulnerability in this repository

Please use GitHub's private vulnerability reporting feature if enabled on the repository. If unavailable, open a non-sensitive issue asking maintainers for a private contact channel **without publishing exploit details or secrets**.

## Scope of this policy

This policy covers defects in the hzkunsec repository itself, not vulnerabilities in unrelated targets found while using these skills. Follow the affected owner's coordinated disclosure policy for external findings.
