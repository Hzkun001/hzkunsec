# Assets

## Brand

The hzkunsec identity uses the project's initials and name in Space Grotesk Bold (weight 700), with tightened letter spacing. It is a typographic treatment, not a library security icon.

- [Logo](logo.svg): cream `hz` on dark green, for avatars and README headers.
- [Light logo](logo-light.svg): dark green `hz` on cream.
- [Transparent mark](logo-mark.svg): dark green initials with no background; use on light surfaces.
- [Wordmark](wordmark.svg): outlined project name for light surfaces.
- [Banner](banner.svg): logo and project name with the research tagline.

Colors: dark green `#202824`, cream `#edece5`, and clay `#9c4937`. Keep the mark's proportions and clear space when resizing.

Typeface: [Space Grotesk by Florian Karsten](https://github.com/floriankarsten/space-grotesk), distributed through [Google Fonts](https://github.com/google/fonts/tree/2861cb7b12f90c0a294a12ed666e381e2211872f/ofl/spacegrotesk). Font source revision: `2861cb7b12f90c0a294a12ed666e381e2211872f`; input font SHA-256: `acad6de1fc93436f5c0f1f4137751ef04f1aea3063e7036535970ffcfbd79f72`.

The lettering is converted to SVG paths, so it does not require an installed font or network request. The banner's supporting tagline uses a system sans-serif font. See [Space Grotesk's SIL Open Font License](LICENSE.space-grotesk). Project-authored layout uses the repository's MIT license.

## Workflow icons

`icons/` contains four unmodified Lucide SVGs: `radar`, `code-xml`, `flask-conical`, and `file-check`. They describe the four skills; they are not the project logo.

Source: [lucide-icons/lucide](https://github.com/lucide-icons/lucide/tree/7faf87628a1ad6175975bc595344337ce14a7db4), revision `7faf87628a1ad6175975bc595344337ce14a7db4`. See [Lucide license](LICENSE.lucide).

All SVGs are self-contained and contain no scripts or external resources.
