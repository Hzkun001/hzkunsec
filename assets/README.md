# Assets

- `logo.svg`: square logo using Lucide's `scan-line` paths on a dark background.
- `banner.svg`: project wordmark with the same icon paths, scaled and colored.
- `icons/`: unmodified Lucide SVGs: `scan-line`, `radar`, `code-xml`, `flask-conical`, and `file-check`.
- `LICENSE.lucide`: upstream license, including its notices.

Source: [lucide-icons/lucide](https://github.com/lucide-icons/lucide/tree/7faf87628a1ad6175975bc595344337ce14a7db4), revision `7faf87628a1ad6175975bc595344337ce14a7db4`.

The logo and banner embed the original icon paths with presentation changes. SVGs are self-contained; the banner uses system fonts.
